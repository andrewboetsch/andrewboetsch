## Featured Work

### BlackBird CLM

An AI-enabled Contract Lifecycle Management platform designed for complex enterprise agreements.

BlackBird CLM is intended to convert lengthy contracts and amendments into structured, actionable information while preserving traceability to the source document.

**Core capabilities include:**

- Contract and amendment ingestion
- Structured contract-data extraction
- Obligation and deadline identification
- Due-date tracking
- Workflow automation
- Audit history
- Human review of AI-generated outputs

The project also uses a multi-agent software-delivery model in which specialized AI agents perform distinct roles across the development lifecycle, including:

- Product management
- Requirements analysis
- UX design
- Software development
- Quality assurance
- Release management

My role includes defining the product concept, workflows, requirements, prioritization, UX direction, agent structure, testing approach, and release process. I also use Claude Code to build, test, and iterate on the application.
